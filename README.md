# Meu Diário da Tireoide

Um diário simples e bonito para quem cuida da tireoide (Hashimoto, hipotireoidismo, nódulos).

- Marcar o remédio em jejum, os 30 minutos de espera e a castanha-do-pará
- Copos de água, movimento, sono, energia, humor e sintomas do dia
- Peso, resultados de exames e datas de consultas
- Relatório em PDF para levar ao médico

Os dados ficam salvos só no aparelho de quem usa. Nada é enviado para nenhum servidor.

Abrir: https://dinizdavidelima-maker.github.io/diario-tireoide/

> Este diário ajuda a organizar a rotina. Não substitui a orientação do médico.
